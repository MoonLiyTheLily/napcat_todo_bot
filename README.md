# Napcat Todo Bot

简单的机器人，开发的初衷是为了Todo，后来是为了熟悉Python和Python的项目组织架构，也是学习AstrBot项目的机会，虽然我现在还看不太懂。

目前只支持基本的todo功能，可以创建、删除、完成todo。同时附带一个定时的未完成Todo通知。太久没回复机器人会触发重力文案，大概是彩蛋。

预期添加功能：

1. 根据Todo单独通知
2. 接入大模型聊天
3. 接入大模型以自然语言创建、删除、完成Todo
4. 自动清理过时Todo（由用户选择是否启用）
5. 提供一个在聊天窗口修改配置的功能

预期项目优化：

1. 统一的Sender
2. 自动的插件加载
3. 统一的配置文件
4. 更多的重力文案
5. 梳理数据库文件，提供统一的数据库接口供继承
6. 添加一个通用的数据库操作接口
